# ClipCloud

> **Never lose a gaming clip again.**
> Automatically upload your clips to the cloud, free up disk space, and access them from anywhere.

## 🚀 Overview

ClipCloud is an automatic cloud backup system designed for gamers and content creators. It continuously watches your clips folder, uploads new recordings to the cloud, and safely removes local copies (optional) to keep your storage clean.

No more full SSDs.
No more lost clips.
Just record, play, and let ClipCloud handle the rest.

---

## ✨ Features

- ☁️ Automatic cloud uploads
- 📂 Watches your clips folder in real time
- 💾 Frees up local disk space after successful upload
- ⚡ Fast background syncing
- 📱 Access your clips from any device
- 🎮 Supports clips from any game
- 🔍 Search and browse uploaded clips
- 📊 Storage usage dashboard
- 🔄 Automatic retry if uploads fail

---

## 🎯 Why ClipCloud?

Gamers generate hundreds of gigabytes of clips every month.

Instead of manually moving files or deleting old recordings, ClipCloud automatically:

1. Detects new clips.
2. Uploads them securely to the cloud.
3. Verifies the upload.
4. Optionally deletes the local copy.
5. Keeps your storage clean without losing memories.

## 🛠️ How It Works

